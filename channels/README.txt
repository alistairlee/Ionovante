IONOVANTE VIDEO LIBRARY
=======================

UPLOAD
Copy this entire folder to your web server, preserving the assets folder.
The page entry point is index.html.

ADOBE LEARNING MANAGER
After publishing, use the public URL of index.html as the Web page source for
your Adobe Learning Manager channel, then select Test now to confirm that all
15 videos are detected.

FILES
- index.html: responsive video-library page and crawler source
- assets/wordmark.png: dark wordmark for the light header
- assets/wordmark-white.png: white wordmark for the dark footer
- assets/social-preview.png: optional social sharing image

VIDEO LINKS
Every row currently links to:
https://www.connectusers.com/content/video/agentic-ai.mp4

You can replace any href value in index.html with a different direct MP4 or
WebM URL later. Keep the table structure, title, and description intact so the
channel crawler can associate the metadata with each video.
